# Roadmap

## M1 - Evidence and Project Governance

**Objective:** Establish a reliable content baseline and project operating model.

**Scope:** Inspect the repository, review supplied career evidence, confirm conflicts and privacy choices, review public GitHub repositories, and create `AGENTS.md` plus the complete `.context` set.

**Dependencies:** None.

**Deliverables:** Approved evidence hierarchy, public project shortlist, privacy boundary, PRD, specifications, roadmap, tasks, progress, issues, learnings, and handoff prompt.

**Completion criteria:** User confirmations are captured; no blocking product questions remain; context files are present and internally consistent.

## M2 - Responsive Portfolio Refresh

**Objective:** Replace outdated and placeholder content with an evidence-led responsive site.

**Scope:** Shared content model, global layout and navigation, hero, about, capabilities, projects, credentials, contact, accessibility, metadata, and responsive behavior.

**Dependencies:** M1.

**Deliverables:** Updated reachable routes and components, selected public repository links, approved public contact actions, and social metadata.

**Completion criteria:** Acceptance criteria in the PRD are satisfied and no unsupported visible content remains.

## M3 - Verification and Release

**Objective:** Prove the static site is buildable and publish the verified state.

**Scope:** Install dependencies if needed, lint, production build and static export, bounded source checks, documentation reconciliation, commit, and push.

**Dependencies:** M2.

**Deliverables:** Passing verification evidence, current context records, Git commit, and pushed branch.

**Completion criteria:** Required checks pass or exact external limitations are documented; the remote branch contains the verified commit.

## M4 - Optional Enhancements

**Objective:** Improve the portfolio after the core refresh without destabilizing the released site.

**Scope:** Verified screenshots and demos, framework upgrades, analytics decision, and duplicate-source cleanup.

**Dependencies:** M3 and separate user approval.

**Deliverables:** Individually scoped future task batches.

**Completion criteria:** Not part of the current release.
