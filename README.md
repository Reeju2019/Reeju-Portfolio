# Reeju Bhattacherji — Portfolio

Responsive, evidence-led portfolio for Reeju Bhattacherji, focused on data analytics, data engineering, supply-chain automation, and applied AI.

Live site: [reeju2019.github.io/Reeju-Portfolio](https://reeju2019.github.io/Reeju-Portfolio)

## Stack

- Next.js Pages Router with static export
- React, Tailwind CSS, and Framer Motion
- GitHub Pages deployment through GitHub Actions

## Routes

- `/` — positioning and confirmed impact
- `/about` — experience, education, and skills
- `/services` — demonstrated capabilities
- `/work` — selected public GitHub projects
- `/credentials` — certification, publications, and recognition
- `/contact` — approved public contact channels

## Local development

```bash
npm ci
npm run dev
```

Verification:

```bash
npm run lint
npm run build
```

The production build is exported to `out/`. Project requirements, evidence boundaries, tasks, progress, and decisions are maintained in [`.context`](./.context/).
